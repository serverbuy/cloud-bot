# Cloud – Discord Bot

Discord-Bot (discord.js v14) mit Moderation, Tickets, Rollen, Voice-Create, Economy, Level, Giveaways und 150+ Commands.

Panel: https://serverbuy.github.io/x_xclub/bot/

## Gratis 24/7 auf Render

1. render.com → mit GitHub anmelden → **New → Blueprint** → dieses Repo wählen.
2. Render liest `render.yaml` automatisch und fragt nach `DISCORD_BOT_TOKEN` → Token aus dem Discord Developer Portal einfügen.
3. **Apply** → warten, bis der Build fertig ist.
4. Damit der Bot nicht einschläft: bei uptimerobot.com einen HTTP-Monitor auf
   `https://<dein-service>.onrender.com/api/healthz` alle 5 Minuten anlegen.

Den Token niemals ins Repo schreiben – nur bei Render unter „Environment“.
